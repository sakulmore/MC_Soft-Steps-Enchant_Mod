# Minecraft (Fabric) - Soft Steps Enchant Mod
**Soft Steps Enchant** introduces a brand new, highly sought-after enchantment to the game: **Soft Steps**. Designed for brave explorers, this enchantment allows you to navigate the dark depths of Ancient Cities with ease. When equipped, your footsteps are completely muffled, preventing Sculk Sensors from detecting your movement and ensuring you won't accidentally summon the Warden.

# Requirements
- Fabric API
- Mod Menu
- Cloth Config
